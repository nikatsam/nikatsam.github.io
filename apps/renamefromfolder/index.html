RenameFromFolder

Prefix every file in a folder tree with its parent folder's name. You see each change first, and you can reverse the whole batch afterwards. Works on Windows 10 and 11.

Who it is for: For anyone who keeps files in well-named folders and wants the filenames to match.

What it does

  • Prefixes each file with the name of its parent folder, including subfolders
  • Shows every planned rename before anything is applied
  • Reverses a whole batch whenever you need to
  • Runs on Windows 10 and 11
