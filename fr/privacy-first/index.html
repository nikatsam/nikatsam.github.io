Confidentialité d'abord

Des outils qui ne vous surveillent pas

Chaque outil que je crée repose sur une règle : il doit faire son travail sans collecter de données inutiles. Voici ce que cela signifie concrètement, et ce que cela ne couvre pas.

Pourquoi c'est important

La plupart des logiciels Windows sont financés par les données qu'ils collectent. Le nom de vos fichiers, vos photos, vos reçus et vos habitudes peuvent finir dans des profils que vous n'avez jamais acceptés. Pour des outils qui touchent à des fichiers personnels, c'est un mauvais compromis.

La règle de base est donc simple. Si une fonction a besoin de vos données, elle doit s'exécuter sur votre PC. Si elle n'en a pas besoin, elle ne devrait pas les demander.

Ce que je vise dans chaque application

  • Aucun suivi. Pas d'identifiants publicitaires, pas de kit d'analyse et pas de télémétrie cachée dans les applications elles-mêmes.
  • Aucun compte. Vous ne devriez pas avoir à vous inscrire pour utiliser un outil.
  • Hors ligne d'abord. Le travail se fait sur votre appareil. Lorsqu'un téléchargement facultatif est nécessaire, comme un modèle d'IA, cela est indiqué dès le départ.
  • Des politiques en langage clair. Chaque application a sa propre politique de confidentialité. Lorsqu'elle existe, le site de l'application y renvoie.

À propos de ce site web

Ce site web est un ensemble de pages statiques hébergées sur GitHub Pages. Il ne fait que décrire les applications ; les engagements de confidentialité ci-dessus s'appliquent aux applications.

GitHub, en tant qu'hébergeur, conserve ses propres journaux serveur standard, selon sa propre politique de confidentialité. Je ne peux pas les désactiver et je n'y ai pas accès. Si vous voulez savoir ce qu'il enregistre, lisez la déclaration de confidentialité de GitHub.

Ce site web utilise Google Analytics pour compter les visites et voir quelles pages sont consultées. Google Analytics dépose des cookies et envoie à Google des données de visite, comme les pages consultées, votre localisation approximative et le type d'appareil. Découvrez comment Google utilise les données des sites qui font appel à ses services. Vous pouvez le bloquer avec les paramètres de confidentialité de votre navigateur ou avec le module de désactivation de Google.

Ce que cette page ne couvre pas

Chaque application est un produit distinct avec sa propre politique, et le Microsoft Store a ses propres conditions pour les téléchargements et les achats. Si un point de cette page entre en conflit avec la politique d'une application, c'est la politique de cette application qui s'applique.

Questions ou problèmes

Si une application ne correspond pas à ce qui est écrit ici, utilisez le lien « Signaler un bug » sur la carte du projet concerné. C'est le lieu public pour le signaler.
